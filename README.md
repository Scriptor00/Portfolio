# Portfolio Personale - Carlo Dicuonzo

Questo è il mio sito portfolio sviluppato con **React + Vite** per il frontend e **ASP.NET Core** per il backend.  
Mostra i miei progetti, competenze e include un modulo di contatto.

> ⚠️ Progetto attualmente in sviluppo. Alcune sezioni potrebbero non essere definitive.

## 🛠 Tecnologie utilizzate

- **Frontend:** React, Vite, TypeScript, Tailwind CSS
- **Backend:** ASP.NET Core
- **Versionamento:** Git + GitHub
- **Containerizzazione (in futuro):** Docker

## 🚀 Come eseguirlo localmente

### 1. Clona il repository

```bash
git clone https://github.com/Scriptor00/Portfolio.git
cd Portfolio

### 2. Avvia il backend (ASP.NET Core)
Assicurati di avere .NET SDK installato.
Poi, entra nella cartella del backend e avvialo:

bash
-cd backend
-dotnet restore
-dotnet run

3. Avvia il frontend (React + Vite)
Assicurati di avere Node.js installato.
Poi, entra nella cartella del frontend:

bash
-cd frontend
-npm install
-npm run dev
